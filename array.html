Arrays

Arrays are the foundation of data structures. They store elements in a contiguous block of memory and are indexed starting from zero.

Basic Operations

  • Access: O(1)
  • Update: O(1)
  • Insert/Delete at end: O(1) for dynamic arrays
  • Insert/Delete in middle: O(n)

Memory Layout Illustration

C++ Example

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {1, 2, 3, 4, 5};

    cout << "Array elements: ";
    for (int i = 0; i < 5; i++) {
        cout << arr[i] << " ";
    }
    return 0;
}
